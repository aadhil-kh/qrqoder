# QRQoder - Issue Tracker

> **This repository is the official issue tracker for [QRQoder](https://apps.apple.com/app/id6824455141), a QR code generator for iPhone, iPad and Mac.**
> The app's source code is **not open source** and is not hosted here.

---

## About the App

**QRQoder** makes QR codes that look like your brand and still scan everywhere. Choose what the code does, style it and export it, all on your device. It supports **30+ code types**, a design editor that checks every code as you work, bulk generation from spreadsheets, and vector export, with no account and no tracking.

**Coming soon to the App Store** for iPhone, iPad and Mac. Microsoft Store (Windows) and Flathub (Linux) may follow.

[![Download on the App Store](https://devtpro.app/assets/media/app-store.svg)](https://apps.apple.com/app/id6824455141)

## Features

- **30+ Code Types**: Website, Text, Email, Phone, SMS, Wi-Fi, Contact (vCard), Calendar Event, Location, WhatsApp, Telegram, Signal, Zoom, Teams, Google Meet, one-time passwords (TOTP/HOTP), and payments such as SEPA transfers, Swiss QR-bills, UPI and Bitcoin
- **Input Checks**: Every form checks what you type and says what to fix before you share a code
- **Design Editor**: Body, eye-frame and eye-center shapes, solid colors and gradients, transparent backgrounds, your own logo or a built-in icon, and frames with your own call to action
- **Scan Guidance**: Contrast, error correction, logo size and data density are checked as you design, with clear advice when a code might not scan
- **Templates**: Built-in templates, plus your own to reuse a design
- **Library**: Saved codes stay fully editable, with favorites, search and filters
- **Bulk Generation (Pro)**: Turn a CSV, TSV or Excel spreadsheet into hundreds of codes in one run, with every row checked first
- **Export**: PNG and JPEG at any size; SVG and PDF vector files (Pro); save to Photos or Files, or share
- **7 Languages**: English, German, Spanish, French, Italian, Japanese and Portuguese (Brazil)
- **Private and Offline**: Codes are made on your device; no account, analytics, advertising or tracking

## Filing an Issue

Before opening a new issue, please **search existing issues** to avoid duplicates.

### Bug Report

When reporting a bug, include:
- **App and QR Engine versions** (both shown in Settings within the app)
- **Device and system version** (e.g., iPhone 17 with iOS 26.1, or a Mac with macOS 26.1)
- **App language**, if the problem is in the wording
- **Steps to reproduce** the issue
- **Expected behavior** vs. **actual behavior**
- **Screenshots**, if applicable

If a code doesn't scan, say which code type and design you used and which scanner or phone you tried. **Don't post a code that contains a password, payment detail or other private information**: anyone who sees it can read it.

### Feature Request

When requesting a feature, include:
- A clear description of the feature
- The problem it solves or the use case it addresses
- Any examples or references that help illustrate the idea

### Email

You can also write to [me@aadhil.dev](mailto:me@aadhil.dev), or use **Send Feedback** in the app's Settings.
